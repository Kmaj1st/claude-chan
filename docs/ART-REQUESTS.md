# Art requests (paste into ChatGPT, drop results into assets/generated-inbox/)

No drawing code is used for Claude-chan art. Missing images are generated by an image model; the import tool (scripts/import-generated.mjs) keys, slices and aligns them. Codex is not used.

## Source sprites (MIT, attach as the reference image)

Repo: https://github.com/Chaosnap/Claude_Overdose (MIT, see docs/LICENSES.md). Files are in public/assets/chars/ (webp). Download one file, attach it to ChatGPT with the prompt. Do NOT attach the fan-art reference image.

- BASE = char_close_a.webp (bust, canvas 1536x1536, face box 434,276,747,614)
- FULL = char_stand_wave.webp (standing, canvas 1024x1536, face box 311,38,474,189)

## How to use

1. Open a new ChatGPT chat (image generation on). Attach the reference file named in the sheet.
2. Paste the prompt. Ask for ONE image only.
3. Save the result into assets/generated-inbox/ with a name that starts with the sheet id (for example S1-eyes.png).
4. Run: node scripts/import-generated.mjs (prints what is still missing).

Ordered by value. A free account has a small daily image limit: do one sheet per day, S1 first.

## Common rules (already inside every prompt)

- Flat pure chroma-green background #00FF00, no shadow, no gradient, no green in the character.
- Same character, outfit, line art, colouring and camera as the reference.
- A grid of equal cells, no gaps, no text, no borders. Each cell shows the WHOLE reference image at the same scale and position, only the listed change differs.
- Output canvas: columns x rows of the cell size (importer accepts any size, but the aspect ratio of each cell must match the reference).

## Inbox naming

Files in assets/generated-inbox/ must start with the sheet id (S1..S5). Anything after the id is ignored. The importer reads the layout (columns x rows) and the item names from scripts/art-items.json; edit both together if a request changes.

## Status

Run node scripts/import-generated.mjs --status to list which items are present in assets/generated/ and which sheets are still missing.
