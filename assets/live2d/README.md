# assets/live2d

Put exported Cubism runtime folders here, one per model: `assets/live2d/<name>/<name>.model3.json` plus the moc3, textures, physics, motions and expressions (docs/LIVE2D.md, "Folder layout" and "Export from Cubism Editor").

Everything in this folder except this README is ignored by git: models are not committed by default, and the proprietary Cubism Core (`live2dcubismcore*.js`) is never committed.
